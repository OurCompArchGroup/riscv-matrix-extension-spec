Mzero instruction sets the destination register to zero.

The instruction does not modify the destination register's `mcfg` state. Software shall program the destination `mcfg` explicitly by `msetcfg` before using the zeroed register in a configured matrix operation.

```
#zero 1 matrix register
mzero md  
```

All other non-destination operand fields in the misc format are reserved zero for `mzero`.
