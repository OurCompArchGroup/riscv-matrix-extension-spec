=== Instruction Encoding Summary

This section provides a summary of the func3, uop, and func4 field encodings for all matrix instructions in the simplified specification.

==== func3 Field Encoding

All matrix instructions use func3 = 000.

[cols="^2,^8"]
|===
| *func3* | *Instruction Category*
| 000     | All matrix instructions (Configuration, Zmasync, Load/Store, Matmul, MISC)
|===

==== uop Field Encoding

The uop field distinguishes major instruction categories:

[cols="^2,^8"]
|===
| *uop* | *Instruction Category*
| 00    | Configuration and Zmasync instructions
| 01    | Load/Store instructions
| 10    | Matrix Multiplication instructions
| 11    | MISC instructions
|===

==== func4 Field Encoding by Category

===== Configuration Instructions (func3=000, uop=00)

[cols="^2,^8"]
|===
| *func4* | *Instruction*
| 0000    | minit
| 0001    | msettile{k,ki}
| 0010    | msettile{m,mi}
| 0011    | msettile{n,ni}
|===

===== Zmasync Instructions (func3=000, uop=00)

[cols="^2,^8"]
|===
| *func4* | *Instruction*
| 1000    | msyncregreset
| 1001    | mrelease
| 1010    | macquire
|===

===== Load/Store Instructions (func3=000, uop=01)

[cols="^2,^8,^3"]
|===
| *func4* | *Instruction Type* | *ls bit*
| 0000    | mlae8              | 0 (load)
| 0001    | mlbe8              | 0 (load)
| 0010    | mlce{8,16,32,64} / msce{8,16,32,64} | 0 (load) / 1 (store)
| 0100    | mlate8             | 0 (load)
| 0101    | mlbte8             | 0 (load)
| 0110    | mlcte{8,16,32,64} / mscte{8,16,32,64} | 0 (load) / 1 (store)
|===

===== Matrix Multiplication Instructions (func3=000, uop=10)

[cols="^2,^8"]
|===
| *func4* | *Instruction Type*
| 0001    | Integer matrix multiplication (mmacc.w.b)
|===

===== MISC Instructions (func3=000, uop=11)

[cols="^2,^8"]
|===
| *func4* | *Instruction*
| 0000    | mzero1r
|===
