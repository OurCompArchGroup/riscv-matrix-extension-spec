The function description of stem:[C = A \times B^T] is as follows:
```
# A[i,k] means the element in row i and column k of ms1
# B[j,k] means the element in row j and column k of ms2

for (int i = 0; i < sizeM; i++) {
  for (int j = 0; j < sizeN; j++) {
    for (int k = 0; k < sizeK; k++) {
      C[i,j] += A[i,k] * B[j,k];
}}}
```

==== Matrix Multiply Capability Examples

The `mmacc` instruction is shared across supported type combinations. The actual legal combination is determined by the programmed `mcfg` values and the capability strings reported by `riscv,matrix-isa-caps`.

Each multiply capability string follows the `<input_type_a><input_type_b><output_type_c>` naming rule defined in the programmer's model. Integer type names use `i<width>` or `u<width>`, while floating-point names use direct tokens such as `fp16`, `bf16`, `fp32`, `fp64`, `tf32`, `nvfp4`, `mxfp4`, `mxfp8`, `fp8`, `fp8e4m3`, or `fp8e5m2`.

```
mmacc md, ms2, ms1
```

The maximum matrix shapes depend on TLEN, TRLEN, ALEN, and the active element types selected by `mcfg`.
