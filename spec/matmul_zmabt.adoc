The function description of stem:[C = A \times B^T] is as follows:
```
# A[i,k] means the element in row i and column k of ms1
# B[j,k] means the element in row j and column k of ms2

for (int i = 0; i < sizeM; i++) {
  for (int j = 0; j < sizeN; j++) {
    for (int k = 0; k < sizeK; k++) {
      C[i,j] += A[i,k] * B[j,k];
}}}
```

==== Matrix Multiply Capability Examples

The `mmacc` instruction is shared across supported type combinations. The actual legal combination is determined by the programmed `mtype` values and the capability strings reported by `riscv,matrix-isa-caps`.

For example:

* `i8i8i32` indicates a signed 8-bit source combination accumulated into 32-bit destination elements.
* `bf16bf16s` indicates a BF16 source combination accumulated into FP32 destination elements.

```
mmacc md, ms2, ms1
```

The maximum matrix shapes depend on TLEN, TRLEN, ALEN, and the active element types selected by `mtype`.
