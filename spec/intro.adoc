== Introduction

This document is a matrix extension proposal for RISC-V. 

The extension chooses a decoupled architecture from the vector extension for the flexibility and implementation considerations. This extension defines extra matrix registers and instructions. The instructions include matrix configuration instructions, matrix multiplication instructions (stem:[C += A \times B^T]), matrix and local-vector load/store instructions, accumulator element-wise instructions, matrix-to-local-vector reductions, and matrix misc instructions. Matrix, local-vector, and CPU RVV registers are independent architectural register files.
