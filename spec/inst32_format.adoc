The 32-bit matrix instruction formats fit under the custom-1 (`0101011`) major opcode. The `func3` field is the top-level instruction-category selector. Bits `inst[27:26]` are reserved and shall be written as `0` in all normative encodings. Any bit without an explicitly defined semantic role in the instruction formats below is reserved and shall be written as `0`.

The assigned `func3` values are as follows:

[cols="^2,^8"]
|===
| *func3* | *Instruction Category*
| 000 | Configuration instructions
| 001 | Load/Store instructions
| 010 | Matrix multiplication instructions
| 011 | MISC instructions
| 100 | Zmasync instructions
| 101 | Reserved
| 110 | Reserved
| 111 | Reserved
|===

For instructions that use matrix-register operands, `md`/`ms1`/`ms2` identify the destination (or store source) and source matrix registers. The `d_size` field indicates the destination element size. The `s_size` field indicates the source element size. The `imm3/ctrl` field carries operation-specific control information. Bits `inst[27:26]` are reserved and shall be zero.

The `md`/`ms1`/`ms2` fields are 3-bit wide to index the four tile registers and four accumulation registers.

[cols="^1,1"]
|===
| *md/ms1/ms2[2:0]*  | *Matrix Register Index*
| 000 | tr0
| 001 | tr1
| 010 | tr2
| 011 | tr3
| 100 | acc0
| 101 | acc1
| 110 | acc2
| 111 | acc3
|===

The `msettype` family uses the same 3-bit encoding in its target-selector operand to identify the associated `mtype` register for `tr0`-`tr3` and `acc0`-`acc3`.

For matrix multiplication instructions, `ms1` and `ms2` shall be tile registers (`000`-`011`), and `md` shall be an accumulation register (`100`-`111`). For matrix misc instructions, `md`/`ms1`/`ms2` can be `000`-`111`, according to the specific instruction.

The element sizes of `d_size` and `s_size` are as follows:

[cols="^1,1"]
|===
| *d/s_size[1:0]* | *Element Size*
| 00 | 8-bit
| 01 | 16-bit
| 10 | 32-bit
| 11 | 64-bit
|===

For instructions with GPR operands, `rs1` and `rs2` indicate the scalar source registers. For configuration instructions that use immediate operands, `imm10` carries the immediate payload.

==== Load/Store Instructions

The load/store instruction category uses `func3 = 001`. Bits `inst[27:26]` are reserved and shall be `00`. The `func4` field defines load/store types (A/B/C matrix type, transpose type). `inst[25]` is the `l/s` field indicating load/store direction: `0` for load and `1` for store. The `d_size` field indicates the transferred element size.

....

  {bits: 3,  name: 'md/ms3', type: 2},
  {bits: 2,  name: 'd_size', type: 7},
  {bits: 3,  name: 'func3', attr: '001', type: 8},
  {bits: 5,  name: 'rs1', type: 3},
  {bits: 5,  name: 'rs2', type: 4},
  {bits: 1,  name: 'l/s', type: 6},
  {bits: 2,  name: '0', attr: '00', type: 8},
  {bits: 4,  name: 'func4', type: 5},
], config: {lanes: 1, hspace: 1000}}

.Load/Store Instructions (`func3=001`)
[cols="^2,^2,^8"]
|===
| *func4* | *inst[25] (l/s)* | *Instruction*
| 0000 | 0 | mlae8 (load A matrix)
| 0001 | 0 | mlbe8 (load B matrix)

|===

==== Matrix Multiplication Instructions

The matrix multiplication category uses `func3 = 010`. Bits `inst[27:26]` are reserved and shall be `00`. The `mmacc` instruction is the only architectural matrix multiply instruction in this simplified specification. Its operand typing is validated against the programmed `mtype` state. The currently defined combination is `i8` tile operands accumulated into `i32`.

==== MISC Instructions

The misc instruction category uses `func3 = 011`. Bits `inst[27:26]` are reserved and shall be `00`. The `func4` field is `0000` for `mzero1r`. When `ms1` or `ms2` are not used, these fields are set to zero. For `mzero1r`, the `imm3/ctrl` field (`inst[25:23]`) is fixed to `000`.
